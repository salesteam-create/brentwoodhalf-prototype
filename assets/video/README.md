# Hero video

Drop a looping background clip in here to activate the hero video:

- `hero.mp4`  — required (H.264/AAC, broad support)
- `hero.webm` — optional, smaller; served first when supported

Until a file exists, the hero gracefully shows the still photo fallback.

## Recommended specs
- 8–15s seamless loop, **no audio needed** (it's muted)
- 1920×1080, landscape, ~5–8 Mbps; keep `hero.mp4` under ~6 MB if possible
- Action should sit in the upper-middle (text overlays the lower-left)
